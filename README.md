# API Manual Testing Portfolio (Restful-Booker)

This repository demonstrates manual API testing of the [Restful-Booker API](https://restful-booker.herokuapp.com/) using Postman.

## 📊 Project Overview
- **Tool Used:** Postman
- **Endpoints Tested:** 5
- **Test Types:** Health Check, GET (Read), POST (Create), Negative Testing (404 handling)
- **Pass Rate:** 100%

## 📁 Repository Structure
- [`test-cases.md`](./test-cases.md) — Detailed API test cases.
- [`execution-summary.md`](./execution-summary.md) — Execution results and evidence.
- `Restful-Booker-API.postman_collection.json` — Exported Postman collection (can be imported into Postman to view my requests).
- Screenshots (`.png`) — Evidence of the requests and responses.

## 🚀 How to Review
1. View the `test-cases.md` to see what was tested.
2. View the `execution-summary.md` to see the results.
3. Download `Restful-Booker-API.postman_collection.json` and import it into Postman to see my exact API setups.
